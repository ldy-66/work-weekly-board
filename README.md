# 工作周记

个人工作任务管理网页，入口为 `index.html`，无需安装依赖。内容按“季度目标 → 周任务 → 子任务”组织，子任务支持快速新增、完成、改名和删除。数据保存在当前浏览器的本地存储中，不会自动同步到其他浏览器或设备。新浏览器首次打开时为空白，可通过页面的 JSON 导入/导出功能迁移和备份数据。

## 本地运行

在项目目录运行：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 在线使用

本仓库通过 GitHub Pages 提供网页。GitHub Pages 是公开网址；网页中录入的任务仅保存在使用者自己的浏览器本地存储中，但不要在公开仓库源码中加入个人数据。
